# CXL Icons for react

207 typed icon components generated from the CXL SVG collection.

```tsx
import { SearchIcon } from '@hugocxl/cxl-icons-react';
// Or: import { SearchIcon } from '@hugocxl/cxl-icons-react/search';

<SearchIcon size={24} color="#64748b" />
```

React 18 and 19 are supported. Unlabelled icons are decorative; use `aria-label` for meaningful icons.

Supports refs, platform SVG props, ESM and tree shaking. The default size is 16.
See the [repository](https://github.com/hugocxl/cxl-icons#react) for local tarball
installation, Swift support and contribution instructions. Package preparation
does not imply that this version has been published to npm.
